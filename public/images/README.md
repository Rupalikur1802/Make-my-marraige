# Homepage imagery

The wedding ceremony photograph and emblem were downloaded from image URLs in the user's existing Stitch Desktop Home Page export (project 17821977374160587101, screen 8f547d0292f848f6bdd500335bba32e5) on 26 October 2026. They are retained locally to avoid runtime Stitch dependencies. No image-generation or upload integration was added.

Fonts are self-hosted under src/app/fonts. Inter and Newsreader were downloaded from Google Fonts; their SIL Open Font License notices are retained beside the font files.
